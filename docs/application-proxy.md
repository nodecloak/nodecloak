# 应用代理

「应用代理」为 Windows 或 macOS 桌面程序指定代理节点，与浏览器副本的代理设置分开管理。每次打开 NodeCloak 时保持关闭，保存的规则不会自行开启网络分流。当前源码已加入 macOS 支持；已发布的 5.0.0 仍只提供 Windows 应用代理。

1. 在侧栏打开「应用代理」，添加 HTTP、HTTPS、SOCKS5、VLESS、VMess 或 Hysteria2 节点。
2. 在 Codex、ChatGPT、Claude 对应行选择节点，也可以通过「添加应用」选择其他程序。Windows 选择 `.exe`，macOS 选择 `.app` 应用；未找到的应用可以手动选择。
3. 点击「开启应用代理」，完成系统管理员授权。状态显示「已开启」后，新连接开始按规则分流。
4. 在目标应用中重新连接，再查看「连接与诊断」。这里显示实际匹配到的程序、目标地址和代理节点；「检测节点」只检测节点连通性。
5. 点击「停止应用代理」释放本次创建的网络接口和路由。修改节点或规则前先停止。退出 NodeCloak 或安装应用内更新时也会停止应用代理；只关闭主窗口会继续在后台运行。

可选的「前置代理」支持本机或软路由的 HTTP、HTTPS、SOCKS5 地址。连接顺序为「应用 → 前置代理 → 指定节点 → 目标」。Hysteria2 使用 UDP，前置代理需要支持 UDP 的 SOCKS5。

应用按可执行文件完整路径匹配。Codex 的桌面进程也可能叫 `ChatGPT.exe`，NodeCloak 根据安装位置区分产品，不会只按这个文件名判断。自动识别的已知版本目录可跟随应用更新；手动选择的程序按所选路径匹配。位于其他路径的同名程序不会自动套用此规则。

macOS 选择 `.app` 时会包括包内的主程序及实际可执行的子程序，网络请求由应用自带 Helper 发出时也能匹配。应用更新、移动或更名后，先停止应用代理，再点击「重新识别」；手动选择的应用需要重新选择。共享的系统进程、浏览器或应用包之外的程序不属于该规则。自动识别会核对产品身份，不能仅靠把另一个程序改名为 Codex 或 Claude 来匹配。

如果 Codex 与 ChatGPT 在同一个 `.app` 中，列表显示「Codex / ChatGPT」，两者共用一条应用规则；独立安装的 ChatGPT 仍可单独设置。

开启后会临时创建 sing-box TUN 接口并调整路由，切换时已有连接可能短暂重连。未匹配的程序直连；系统 HTTP 代理和 DNS 配置保持不变。应用自己设置的代理、本机回环流量及共享宿主中的网络请求不保证能由所选程序的规则接管，不提供按应用隐藏 DNS 的保证。

节点不可用时，匹配到该节点的新连接会失败，不会自动改走直连。其他 VPN 或 TUN 已接管默认路由时，先停止它再启动应用代理。程序缺失、管理员授权取消、节点错误和接口释放失败均会显示具体提示；可在「连接与诊断 → 运行记录」查看或复制诊断。

macOS 在切换 Wi-Fi、连接其他 VPN 或从休眠唤醒后会停止应用代理并提示重新开启，避免沿用旧网络的路由。取消管理员授权时保持关闭。停止或退出后只释放本次会话创建的接口和路由，不会删除其他 VPN 的接口。

连接命中规则只能确认流量路径，不能保证网站登录、账号状态或服务可用性。浏览器副本继续使用各自保存的代理设置。
