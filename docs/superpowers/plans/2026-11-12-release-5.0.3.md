# NodeCloak 5.0.3 patch release implementation plan

**Goal:** Publish the current application-proxy protections and CLI / VS Code / WSL integration as a complete patch release on GitHub and the official website.

**Architecture:** Use an exact-source version tag and the existing Windows x64, macOS Apple Silicon / Intel, and Ubuntu x64 build matrix. Keep a draft until every package, updater signature, program-content check and website download hash is verified. Reuse the established Windows package-signing process and atomically activate the website release while retaining rollback files.

**Tech Stack:** Tauri 2, Rust, React, GitHub Actions, existing local certificate tooling, verified SSH/SFTP static deployment.

**Spec:** User request to package and sign all current updates, publish a patch on all supported platforms, and synchronize GitHub and the website.

## Constraints

- Preserve the user's running desktop development session, profiles, credentials, proxy selections and live routes.
- Apply the public release-copy rules in AGENTS.md; certificate/trust verification belongs in private engineering evidence and the direct user report.
- Use the existing certificate as previously authorized; distinguish mathematical signature integrity from certificate trust and independently verify updater signatures.
- Do not publish a partial or failed build. Do not shut down the computer.
- Package Windows x64 installer/portable, macOS ARM64/x64 DMGs and updater archives, Ubuntu x64 deb/AppImage. Linux desktop application proxy remains unsupported; WSL integration is a Windows feature.
- Keep the website's existing SSH host-key validation and atomic release switch. Do not modify the account service or IP website.

## Preflight evidence

243 frontend tests, 41 release/browser/client script tests (including eight release/Apple-ticket checks), version consistency and the frontend production build passed. The Windows full Rust suite passed 400 tests in serial and controlled four-worker runs, with 55 opt-in native checks excluded from the ordinary suite. An initial unrestricted parallel run ended in native status `0xc0000409` without a Rust assertion; the failure is retained privately, alongside both successful complete reruns. The same high-concurrency host behavior was recorded before this feature in the macOS-profile-lock verification plan. The release matrix uses four test workers without omitting assertions and runs the required native checks separately on disposable runners.
