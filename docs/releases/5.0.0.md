# NodeCloak 5.0.0

- Windows 新增独立「应用代理」，可为 Codex、ChatGPT、Claude 或自选程序设置节点，按程序路径分流。此功能暂仅支持 Windows，默认关闭。
- 先保存节点并为已安装应用选择节点，再点击开启并完成 Windows 管理员授权。未匹配的应用直连，系统 HTTP 代理和 DNS 设置保持不变。
- 支持 HTTP、HTTPS、SOCKS5、VLESS、VMess 和 Hysteria2，保留可选的本机或软路由前置代理。Hysteria2 链式连接需要 SOCKS5 UDP 支持。
- 匹配连接与运行记录可显示应用实际命中的节点、目标及收发流量。节点不可用时，已匹配连接不会自动改为直连。
- 停止后释放本次网络接口和路由。修改规则前需先停止；退出 NodeCloak 或准备应用内更新时也会停止。应用自身代理、本机回环和共享宿主流量不保证由所选程序规则接管。
- 浏览器副本继续使用原来的独立代理方式，Chrome、Edge、Firefox 的稳定指纹、MCP、同步和分享功能继续保留。统一应用代理页面的标题与标签样式。

已有副本和修复记录继续保留。提供 Windows x64 安装版和便携版，以及 macOS Apple Silicon 和 Intel 安装包。
