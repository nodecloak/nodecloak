# NodeCloak 4.0.0

- 新增 VLESS、VMess 和 Hysteria2 节点代理，在「代理设置」粘贴链接即可导入，适用于 Chrome、Edge 和 Firefox 副本。
- 每个运行中的副本独立连接节点，不修改系统代理或 DNS，不启用 TUN；关闭副本后停止对应代理。
- 继续支持本机或软路由前置代理。Hysteria2 支持 `hysteria2://`、`hy2://`、单端口、SNI 及链接中的证书验证设置；链式连接需要 SOCKS5 UDP 转发，暂不支持混淆和端口跳跃。
- 节点认证信息保存在系统凭据存储，支持副本复制和加密同步。已有 HTTP、HTTPS、SOCKS5 和 API 代理继续使用。
- 改善浏览器关闭与重启时的进程回收和等待；代理失败时不会自动改为直连。
- 改善 macOS 浏览器副本关闭和再次启动时的兼容性。

同步节点配置的设备需升级至 4.0.0。已有浏览器副本和修复记录继续保留。提供 Windows x64 安装版和便携版，以及 macOS Apple Silicon 和 Intel 安装包。
