# NodeCloak 5.1.0

- 从侧边栏「团队」创建工作区，按对方的 NodeCloak 用户名和邮箱发出邀请。
- 成员加入后，创建者可以为指定成员分配浏览器副本，并设置有效期。成员接受分配后，从「浏览器副本」列表启动。
- 团队副本使用独立的配置快照和接收设备的系统代理。原副本的登录数据、代理设置和备注不随团队副本发送。
- 移除成员或退出团队会撤销对应的团队副本授权。运行中的副本会在下一次授权检查时关闭。

## English

- Create a workspace from **Teams** in the sidebar. Invite someone using their NodeCloak account name and email.
- Once they join, assign a browser profile with an expiration date. Team members accept the assignment and start it from **Browser Profiles**.
- Team profiles use independent configuration snapshots and the receiving device's system proxy. The original profile's sign-in data, proxy settings and notes are excluded.
- Removing a member or leaving a team revokes the corresponding team profile grants. Running profiles close at the next authorization check.
